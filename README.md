# React Starter

A small React + TypeScript app powered by Vite.

## Get started

Requires Node.js 20.19+ or 22.12+.

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. Edit `src/App.tsx` and `src/style.css` to
customize the starter screen.

## Other commands

```sh
npm run build    # Type-check and create a production build in dist/
npm run preview  # Preview the production build locally
```
